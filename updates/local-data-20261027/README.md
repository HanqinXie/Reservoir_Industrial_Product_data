## 恢复

先按仓库原工具恢复 `snapshot-20261027`，再按 [RESTORE_DELTA_使用说明.md](../../tools/RESTORE_DELTA_使用说明.md) 应用本增量。恢复器校验固定基准清单、两份增量清单、每卷与每个文件的SHA-256；未知修改拒绝覆盖，所有新增内容验证后才删除已知旧文件。原始快照缺失的其他年份或未取得数据不会由本增量补造。

本次逐文件核验、分卷完整解码和实际恢复结果见同目录核验记录；GitHub服务端上传校验记录将在发布完成后保存。
