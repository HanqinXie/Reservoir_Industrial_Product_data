# 数据来源、示例参数与适用边界

本目录将“来自原数据的数值”和“用于检验机制的假设”分开记录。模型读取原始研究仓库的相关子集，不需要运行 D26 或安装完整 PyPSA 环境。

## 1. 当前示例的来源

| 项目 | 示例口径 | 来源状态 |
|---|---|---|
| 小湾日入流 | D01 中 1979—2016 年小湾序列 | 已发表研究配套模型输入，非电站实测入流 |
| 固定水耗系数 | `1.85 m³/kWh` | D01 抽取口径；不代表逐时真实水头和效率 |
| 活动库容 | `1.0×10¹⁰ m³` | D01 站点参数口径；不是总库容 |
| 水电装机 | `4200 MW` | D01 站点参数口径 |
| 电解冶炼交流电耗 | `13.203 MWh/t` | D17 IAI 的 2025 年中国 AC 指标，区域统计参考值 |
| 铸造附加电耗 | `0.25 MWh/t` | 示例假设，不是对云铝工艺的实测认定 |
| 合并电耗 | `13.453 MWh/t` | 上述两项的示例合计，不是完整生命周期能耗 |
| 额定产能 | `1000 t/day` | 代表性工厂假设 |
| 持续最低生产比例 | 额定产能的 90% | 探索性假设，不是经工厂确认的长期运行下限 |
| 基准生产与固定交付 | 每天生产 `950 t`，月末交付当月基准总产量 | 标准化交付假设 |
| 购电价 | 丰水期 `450`、枯水期 `650 CNY/MWh` | 经济情景假设，非企业合同或账单 |
| 售电价 | 丰水期 `250`、枯水期 `350 CNY/MWh` | 经济情景假设，非实际成交数据 |
| 电网接口 | 默认双向不限量 | 机制探索边界，可通过输入收紧 |
| 总仓容 | 基准正常周转峰值，加 30 天平均交付量的额外空间 | 情景假设，非交易所库存推算的厂内仓容 |
| 持有费用 | `3 CNY/(t·day)` | 合并持有费假设，不是实测融资与仓储报价 |
| 初末水量 | 均取基准活动库容的 50% | 共同边界假设；库容敏感性不免费增加初始水量 |

默认 `hydro_scale=0.5`，入流水量、活动库容和水电功率容量同时缩放，固定水耗系数保持不变；对应示例活动库容为 `5×10⁹ m³`、功率上限为 `2100 MW`。这称为“小湾来水时序支持的代表性单元”，不能称为真实小湾电站与某铝厂的直供系统。

丰枯季节划分、价格和各项参数均以配置文件与生成的输入表为准。算例年度由入流序列选取，不代表已验证的未来预测。

完整日序列保留 1979-01-01 至 2016-12-31 的 13,880 天及闰日。程序按全年总入流的 20%、50%、80% 分位附近选择枯年 1993、平年 1988 和丰年 1990；这种分组不等同于季节性或连续干旱识别。1979—2016 也是源模型使用的水文年份，不是小湾建成后的 38 年运行记录。

## 2. 最容易混淆的口径

### D01：能量等价入流与水量

原始文件包括 `daily_hydro_inflow_per_dam_1979_2016_GWh.pickle` 和 `daily_hydro_inflow_per_dam_1979_2016_m3.pickle`。GWh 为能量口径，m³ 为水量口径；两者不能直接互换列名。来源介绍见 [D01 README](../../../dataset/D01_Nature_Energy_Industrial_Overcapacity/extracted/data/data/README.md)，原始发布记录见 [Zenodo](https://zenodo.org/records/19600477)。

本版本保留 m³ 文件中的小湾列，并从已校验的 CSV 运行。原始 GWh 文件的换算口径隐含约 `1.90 m³/kWh`，与采用的站点表 `1.85 m³/kWh` 不同，因此不混合使用。原始 initial 文件的小湾数值 `1.1885×10¹⁰ m³` 也未被直接当作活动水量；本版本单独明确初末活动水量假设。

### D17：AC、DC和库存产品

IAI AC 指标包括整流和正常冶炼辅机，统计终点为电解槽出铝液，不含铸造及炭素厂用电；DC 是整流后的过程指标。AC 与 DC 不能相加，AC 已包含的辅机不能再次计入。

本模型将可储存产品解释为铝锭一类固态成品。示例额外加入的铸造电耗是明确假设；它不把高温铝液视为可以无代价跨季存放的商品。来源为 [IAI 官方统计](https://international-aluminium.org/statistics/primary-aluminium-smelting-energy-intensity/)，仓库文件为 [D17 API JSON](../../../dataset/D17_IAI原铝冶炼能耗强度/primary-aluminium-smelting-energy-intensity_当前官网API完整响应.json)。

### 产能余量与需求

最低负荷按额定产能计算，不按订单或基准交付计算。年度名义产能减去年度产量，也不能直接解释为每个丰水月份都可以调用的生产余量。本版本没有检修、槽龄和供料约束，使用者应将配置中的产量边界理解为已经约定好的可用范围。

## 3. 其他资料怎样使用

| 资料 | 合适用途 | 当前不能替代的参数 |
|---|---|---|
| D15/D16 国家及云南统计 | 电力与工业规模、年度背景和口径校核 | 单库入流、单厂生产时序；氧化铝和铝材不能代替原铝 |
| D18 IAI原铝产量 | 国家/区域生产背景 | 单厂交付合同和云南月度原铝产量 |
| D19 云铝年报 | 生产规模、产品结构、年度经营数据的参考 | 日内最低负荷、复产过程、实际逐日交付与仓容 |
| D20 上期所铝价 | 库存价值的参考区间 | 厂门合同价、融资利率或仓储单价 |
| D21 上期所库存和仓单 | 交易所库存背景 | 工厂可调用库存或仓容 |
| D22及标准/规则 | 交易、计量、能源统计和安全边界 | 逐时成交电价、购售电合同或实际交换限值 |

本版本不依据期货价格和交易所库存预测企业利润，也不将市场规则转换成未经核对的实际电价。D23 尚未取得的企业账单和计量资料仍是实际案例校准的缺口。

## 4. 当前模型边界

- 固定水耗系数；未描述水头变化和梯级联系。虽可输入蒸发、最小总下泄及时变库容上下限，默认示例未据项目文件校准这些工程边界。
- 连续生产且不启停；未描述停槽、复产、长短时负荷调节的工艺差异。
- 固定产品交付，库存非负；不通过欠交货制造节约。
- 价格和接口能力外生；允许售电，不预设所有电只能在厂内消纳。
- 各方案使用共同初末水量和库存；不会通过期末放空额外获取收益。
- 已知完整输入时序；未进行滚动预测、未见年份部署或极端事件概率校准。
- 使用统一的现代工业参数和价格情景配合历史来水，不是对历史年份企业财务的还原；数据截至 2016 年，不能声称复现了 2022 年等近期实际干旱。
- 比较可变运行费用；未优化仓库建设、产线扩建、收益分配或合同。

因此，本版本能回答“这些约束与输入下是否存在协调收益、来自哪项调整、何时消失”。实际电站和工厂能否执行，需要在后续补充工程边界及生产资料。
